## Defects found and fixed

1. **llms-full.txt was missing Dispatch Nº 111.** The file was generated by the 08-20 SEO/GEO
   pass before that night's publish run landed, and the publish run did not regenerate it, so
   the full-text GEO surface stopped one dispatch short of the site (63 entries against 64
   wired posts, no `never-sync-to-shipstation` entry). Fixed: the Nº 111 entry now leads the
   file (newest first), in the established format: h1 title, metadata block, dek, full body as
   markdown, playbook spec in a code fence, 3-question FAQ matching the page's FAQPage
   structured data.

2. **All 163 callouts were absent from llms-full.txt**, despite the file's own spec (per the
   08-20 SEO report: "headings, lists, blockquotes, and callouts preserved in document
   order"). Blockquotes made it in; the `div.callout` blocks did not, on any of the 63 posts.
   Fixed: callouts now render as `> ◆ NOTE: ...` blockquote lines in document order, 165
   total across 64 entries (163 pre-existing + 2 in Nº 111).

**Fix method and verification.** A converter was built and validated by round-tripping: with
callouts disabled it reproduces all 63 previously shipped entries **byte-for-byte**, so the
regenerated file is provably the shipped file plus exactly the two additions. Cross-check:
stripping the callout lines and the Nº 111 entry from the new file reproduces the pre-edit
file byte-identically. The shipped file re-verifies clean on the SEO pass's own checklist:
65 h1 lines outside fences (64 titles + file header), 134 balanced fence markers, 64 unique
canonical URL lines, 64 FAQ sections with 318 questions, zero HTML leftovers, zero em/en
dashes or curly double quotes, and all 165 callout texts confirmed present against the source
pages. File grew 1.04 MB to 1.13 MB.

  report's standing note about an uncommitted tree is stale. Today's llms-full.txt repair is
  the only uncommitted change; nothing on blog.dugong.live moves until it is committed and
  pushed.

  QA/SEO/publish collision is exactly how today's llms-full gap arose), and delete the two
  rejected drafts on a supervised run.
