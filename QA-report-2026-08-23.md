playbook specs.** The publish workflow's new llms-full regeneration step (adopted after the
08-20/08-22 recommendation) collapsed each post's `<pre id="playbook">` block into a single
run-on line outside any code fence, e.g. `# trigger On every new order ... # steps 1. ...`,
against the file's own spec (playbook spec in a code fence, line structure preserved), which
all 63 older entries follow. Worse, on Nº 112 and Nº 111 the flattening also swallowed the
prose paragraph that follows the playbook on the page ("Step three is the heart...", "Step
two is the heart...") into the same line, so paragraph structure was lost too. Today's SEO/GEO
pass checked fence balance and URL uniqueness, which both still passed, so it missed this.

Fixed: each flattened line replaced with a fenced block reproducing the source page's
playbook verbatim (tags stripped, entities decoded, original line breaks and indentation
kept), and the two swallowed paragraphs restored as their own paragraphs after the fence.
