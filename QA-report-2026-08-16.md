## Addendum: Search Console defect, found and fixed same day

Google Search Console flagged **Unparsable structured data > Duplicate unique property** on
`https://blog.dugong.live/` (crawled 17 Aug). Root cause: the Person node (`#priya-singh`) in
the index @graph carried the `url` property twice, once beside `@id` with the correct
`.../#priya-singh` value and a second time after `knowsAbout` with the bare site root. Python's
JSON parser silently keeps the last duplicate, which is why every prior "JSON-LD parses"
check passed while Google's stricter parser rejected the block. Fixed by removing the stray
second `url`; the first, matching the `@id` all 63 posts' author references resolve to, stays.
A duplicate-key scan (object-pairs level, all JSON-LD blocks site-wide) now returns zero and
has been added to the audit so this class of defect cannot pass silently again.
